# Power Automate Ticket Management System

## Overview

An automated ticket management solution built with Microsoft Power Automate, Outlook, Excel and Microsoft Teams.

The system automatically registers incoming support emails, generates unique Ticket IDs, tracks email conversations and notifies the support team in Microsoft Teams.

---

## Business Problem

Managing support requests manually caused:

- Duplicate tickets
- Difficult conversation tracking
- Delayed responses
- Manual data entry
- Lack of ticket history

This automation centralizes ticket creation and tracking while keeping all interactions linked to the same conversation.

---

## Solution

The workflow automatically:

- Detects incoming emails
- Creates a unique Ticket ID
- Stores ticket information in Excel
- Tracks replies using Conversation ID
- Updates existing tickets instead of creating duplicates
- Sends notifications to Microsoft Teams
- Maintains a complete ticket history
